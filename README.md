
# Gannon Cyber Defense Club

The official web application for the Gannon University Cyber Defense Club.

This project is being developed collaboratively by members of the Cyber Defense Club to provide a central hub for club information, cybersecurity resources, events, and real-time cyber threat information.

## Project Goals

- Build a full-stack web application for the Gannon Cyber Defense Club
- Display current cybersecurity threats and vulnerabilities
- Integrate cybersecurity APIs such as the NIST NVD and CISA KEV
- Display CVE and CVSS information
- Provide information about club officers, events, meetings, and resources
- Provide information about Gannon iHack
- Give club members hands-on experience with:
  - Web development
  - APIs
  - Databases
  - Cybersecurity
  - Git and GitHub
  - CI/CD
  - Team-based software development

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- GitHub
- GitHub Actions
- Vercel
- NIST NVD API
- CISA KEV
